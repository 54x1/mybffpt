# Support

mybffpt is a **client-side-only** application — there is no backend, account
system, or server to contact for support.

- **Bugs and feature requests**: open a [GitHub
  Issue](https://github.com/54x1/mybffpt/issues).
- **Security issues**: see [SECURITY.md](SECURITY.md) — do not open a public
  issue for these.
- **"How does this work?" / privacy questions**: check the in-app **About →
  Security & Privacy FAQ** first; it covers data storage, encrypted share
  codes, and general privacy tips.
- **Accessibility issues**: see [ACCESSIBILITY.md](ACCESSIBILITY.md) for how to
  report these.
