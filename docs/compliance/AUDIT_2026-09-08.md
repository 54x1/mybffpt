## Baseline strengths (no action needed)

- No server, accounts, analytics, or network egress; CSP `script-src 'self'`.
- Correct cryptography using the browser's Web Crypto: PBKDF2-SHA256 at 600,000 iterations, AES-256-GCM with fresh random salt and IV, password verifier, authenticated encryption for at-rest and share/export data. 56 unit tests cover the lifecycle.
- Share links use the URL fragment; imports are size-capped and expiry-checked; CSV export guards against formula injection; no `v-html`, `eval`, or `innerHTML` with unescaped data.
- Production console is quiet (`DEBUG_IMPORT` gate).
- CI already ran type-check, unit, licence header check, third-party notice check, build, `npm audit`, and an axe-core scan; Dependabot enabled; lockfile v3 with integrity hashes.
- Licensing governance (AGPL headers, notices, allow-list) is unusually complete.
