- **F19 closed.** ESLint 10 installed with a flat config (`eslint.config.mjs`);
  `npm run lint` is part of `verify`. The baseline was driven to zero errors:
  dead code removed from `ChartsSection.vue` (~400 lines, verified unused via

  a latent HSL→RGB wrap bug in `themeColors.ts` fixed while cleaning an unused

  output is warnings only (`no-explicit-any` et al.), tracked as ongoing
  hygiene rather than a gate.
- **F20 closed.** Every workflow `uses:` reference now points at an immutable
  commit SHA resolved from the GitHub API (annotated tags dereferenced to their
  target commits), with the human-readable tag kept as a trailing comment.
- **F21 closed.** Four new suites — `csv`, `transactions`, `rules`, `query` —
  add 82 unit tests covering CSV parsing, amount-format normalisation, column
  inference (including Wise Mobile/Desktop and split debit/credit layouts),
  row→transaction conversion, stable dedup keys, the transaction schema
  validator/normaliser, preset category/tag rules, and the smart-query parser
  and matcher. Writing them found a real defect: `parseAmountNumber` stripped
  commas before testing the European decimal-comma pattern, so amounts like
  `1.234,56` silently became `1.23456`; the parse order is fixed and covered.
